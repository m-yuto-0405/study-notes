# Anthropic まとめ

## 会社概要

- **設立**: 2021年
- **創業者**: Dario Amodei（CEO）、Daniela Amodei（社長）ほか、元OpenAIメンバー中心
- **本社**: サンフランシスコ
- **ミッション**: 「AIの安全性研究と信頼性の高いAI開発」

## 主なプロダクト

### Claude
Anthropicが開発するAIアシスタント。安全性と誠実さを重視した設計が特徴。

| モデル | 特徴 |
|--------|------|
| Claude Opus | 最高性能・複雑なタスク向け |
| Claude Sonnet | 性能とコストのバランス型 |
| Claude Haiku | 軽量・高速・低コスト |

### Claude Code
ターミナルで動くAIコーディングアシスタント。このアプリも Claude Code で開発中。

## Constitutional AI（CAI）とは

Anthropicが提唱するAI安全性のアプローチ。「AIに憲法（原則）を持たせ、自分の出力を自己評価させる」手法。有害な出力を減らすことを目的としている。
